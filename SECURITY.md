# Security Policy

This repository is the showcase site for Jolly Panda Profile (samples of finished profiles). It is a static site generated at build time: it has no database, no backend functions and no authenticated user data of its own.

## Reporting a Vulnerability

If you discover a security issue affecting this site (for example, an XSS vector, or an issue with a dependency), please report it privately rather than opening a public issue:

* Email: **hello@jollypanda.ir**
* Include a description of the issue, steps to reproduce, and its potential impact.

Please allow a reasonable amount of time for a response and a fix before disclosing the issue publicly.

## Scope

This site does not store passwords, payment details, or any authenticated session data. Reports about third-party services we rely on (Vercel, GitHub) should go to that service's own security contact rather than to Jolly Panda.
